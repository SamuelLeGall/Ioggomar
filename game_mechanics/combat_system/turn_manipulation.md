# Turn Manipulation Strategies

## **Overview**

It's a key point of the system because it will add a lot of depth to how a player can affect the flow of battle. The more interactive the timeline is, the more satisfying the combat will be.

Players can manipulate the turn system in various ways to **control combat flow**.

## **Key Strategies**

- **Speed Buffs:** If you boost an ally’s speed, enemy actions scheduled for later **might be lost** when the turn ends.
- **Delaying Enemies:** If you slow an enemy down, their actions might **not happen within the turn’s timeline**.
- **Action Interruption:** Some actions could **cancel enemy ultimates** by forcing the turn to end.

Certain actions, buffs, and debuffs **change the timeline**, offering tactical depth.
