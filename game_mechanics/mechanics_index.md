# Game Mechanics Overview

This folder contains a breakdown of the core mechanics that govern gameplay. Each system is designed to work together to create a strategic and dynamic combat experience.

## **Combat System**

The combat system is structured around a hybrid turn-based system with speed-based mechanics, tiredness, stealth, threat, and evasion. Each subsystem works together to ensure depth in decision-making.
